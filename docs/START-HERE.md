# HA Soundbar Settings: start here

**Continuing this tool? Read [the detailed handover](HANDOVER.md).** For pictures and operation, use the [manual](USER-MANUAL.md) and [offline demo](../demo.html).

Additional Samsung soundbar levels, mode and switches through the existing HA SmartThings connection. Displayed advanced settings are last accepted commands, not confirmed hardware readback.

**Start with:** Find the controls. First confirm the soundbar already appears in the official SmartThings integration in HA.

**Source:** this is a private source checkpoint, not a live-system mirror. Check [the source manifest](../SOURCE-MANIFEST.json) and current working files before merging.

**Keep your work safe:** Connection credentials remain with HA’s existing SmartThings integration. Entity restore retains accepted settings for display, but remembered values do not prove current hardware state. Internet access to SmartThings is required.
